# 📺 Auto-看看IPTV聚合

#### 这是一个基于 Node.js 和 GitHub Actions 构建的 **自定义纯净版 IPTV 直播源与 EPG 节目单自动聚合系统**。
#### 彻底告别直播源失效、节目单错乱、EPG 文件过大导致播放器卡顿等痛点。只需配置一次，系统每天清晨为你自动抓取、清洗、合并出专属的极速直播源！每天按时自动抓取大神源，自动抓取节目单，同步筛选。hn仅hn移动，cn全国通。

## ✨ 核心特性

* 🎯 **按需提取，拒绝臃肿**：采用模板驱动 (`template.txt`)。只抓取你模板里定义好的频道（如央视、卫视、精选电影），自动过滤其他几千个无用垃圾频道。

* ⚡️ **极速 EPG (秒开体验)**：
  * **按天截断**：智能剔除过去的历史节目单，仅保留“今天+明天”的数据，将上百 MB 的 EPG 文件极限压缩至几百 KB，电视/手机加载零延迟。
  * **多源互补**：支持配置多个 EPG 源，当某源缺少当天数据时，自动使用备用源按天无缝填补。

* 🛡️ **纯净无广 & 中文优化**：
  * **繁转简**：内置 `opencc-js` 引擎，自动将港台源的繁体中文转换为标准简体。
  * **自动去广告**：强大的正则过滤，自动抹除节目单中“由 xxx 提供服务”、“欢迎关注微信”等牛皮癣广告。

* 🤖 **完全自动化 (Serverless)**：借助 GitHub Actions，每天准时运行，自动抓取全网最新源并推送到本仓库。

## 📂 目录结构

* `template.txt` - **核心配置文件**。在这里按行填入你想要的频道名称（支持分组），所有脚本都会以此为基准进行提取。
* `index-hn.js` / `index-cn.js` - 直播源 (M3U) 抓取与生成脚本。负责去重、匹配频道，并强制绑定专属 EPG。
* `epg-merge.js` - EPG 节目单超级聚合脚本。负责解压 `.gz` 源、按天过滤、去广告、简繁转换以及精准合并。
* `.github/workflows/update.yml` - 自动化工作流配置文件。
* `www.m3u` - 自定义频道

## 🚀 部署与使用指南

### 1. 个性化配置
修改 `template.txt`，定制你的专属频道列表。打开 `epg-merge.js` 顶部，可以调整是否保留昨天数据，以及添加新的广告屏蔽词。

将各个 JS 脚本顶部的 `CUSTOM_EPG` 变量，替换为你自己仓库的 Raw 链接：
`https://raw.githubusercontent.com/你的用户名/你的仓库名/main/epg.xml`

修改 `index-hn.js`，将收集的链接替换上。

### 2. 获取订阅链接 (请使用 Raw 链接)
运行成功后，仓库会生成对应的文件。请将以下链接填入你的播放器（如 APtv, TiviMate, Kankan 等）：

* **直播源**：`https://raw.githubusercontent.com/你的用户名/你的仓库名/main/hn.m3u`

> 💡 *提示：节目单 `epg.xml` 已内置在 M3U 头部，播放器会自动加载，无需另外配置。*
